🖼️ Image Paste Feature Test

Test the Ctrl+V image paste functionality before deploying to the extension.

How to Test:

  1. Copy an image to your clipboard:
    • Take a screenshot (Win+Shift+S on Windows, Cmd+Shift+4 on Mac)
    • Right-click an image on a webpage and select "Copy Image"
    • Copy an image from an image editor
  2. Click inside the textarea below
  3. Press Ctrl+V (or Cmd+V on Mac)
  4. The image should be inserted as markdown with base64 encoding
  5. Click "Preview Images" to see the rendered output
Note: Images are stored as base64 data URLs. Large images will create very long text strings.
