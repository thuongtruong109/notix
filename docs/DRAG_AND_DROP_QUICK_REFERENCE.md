# 🎯 Drag and Drop - Quick Reference

## How to Reorder Notes

### Step 1: Hover Over a Note

Move your mouse over any note in the list to see the drag handle (☰).

### Step 2: Click and Hold

Click on the note and hold the mouse button down.

### Step 3: Drag to New Position

Move the mouse up or down to drag the note to your desired position.

### Step 4: Release to Drop

Release the mouse button to drop the note in its new position.

## Visual Indicators

| Indicator          | Meaning                          |
| ------------------ | -------------------------------- |
| ☰                  | Drag handle - Click here to drag |
| 50% opacity        | Note being dragged               |
| Blue dashed border | Valid drop zone                  |
| Teal highlight     | Mouse over drag handle           |

## Troubleshooting

### Drag handle not showing?

✓ Make sure you're hovering over the note
✓ Try moving mouse slowly over the note

### Can't drop note?

✓ Drop on another note item (not empty space)
✓ Ensure you're in list view

### Order not saving?

✓ Check Chrome sync is enabled
✓ Try reloading the extension
✓ Ensure storage space available

### Order different in other tabs?

✓ Enable auto-sync in settings
✓ Reload all open tabs
